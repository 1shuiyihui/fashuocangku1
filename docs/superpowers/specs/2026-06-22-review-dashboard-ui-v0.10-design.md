# v0.10.0 周度/月度复盘 UI 重构设计

## 目标

把 `周度/月度复盘` 从 Markdown 直出页面重构为可行动的复盘驾驶舱，让用户先看到训练队列、学习概况、高频薄弱点、高频错因，再安排下一轮训练。

## 范围

- 页面顶部展示复盘流程：选择周期、查看训练队列、定位高频问题、安排下一轮训练、导出复盘。
- 新增复盘 KPI：新增训练点、完成训练、高风险考点、待复训。
- 复盘前训练队列保留真实跳转动作，点击后进入对应训练点的苏格拉底训练。
- 学习概况按科目显示完成度。
- 高频薄弱考点、高频错因和关键结论用结构化卡片展示。
- 下一轮训练计划按 Day 生成卡片，包含科目、掌握度、推荐模板和预计时间。
- Markdown 原文只作为折叠预览和下载，不再直接铺满页面。

## 非目标

- 不修改数据库 schema。
- 不改周/月筛选的数据来源范围；当前仍沿用已有弱点和训练记录集合。
- 不改 AI 生成逻辑、OCR、RAG 或课程生成。
- 不新增只做装饰、没有业务动作的按钮。

## 数据影响

本次仅修改 UI、纯汇总函数和文档。没有迁移，没有写入或删除用户数据。

## 验收标准

- 页面显示 `v0.10.0`。
- 复盘页能看到 `把阶段结果转成下一轮训练`、`复盘前训练队列`、`下一轮训练计划`。
- 训练队列和计划卡片中的开始训练按钮仍跳转到真实训练点。
- Markdown 报告仍可下载。
- 全量测试和浏览器 smoke 通过。
