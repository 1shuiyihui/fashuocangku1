# v0.5.0 可执行训练计划设计

## 目标

把资料生成课程从“7 天大纲”升级为“可直接执行的训练计划”，并把课程小节导入入口改成更准确的“导入为训练点”。本版本同时加入一个轻量首次使用指引，帮助第一次打开系统的人知道从哪里开始。

## 范围

本版本只改应用代码、提示词、展示文案、测试和文档，不改变数据库结构，不迁移 `data/fashuo.db`，不改 `data/uploads/` 或 `data/documents/`。

## 功能设计

### 1. 导入入口改名

课程小节下方当前有科目选择框和导入按钮。v0.5.0 调整为：

- 科目选择框标签：`训练点科目`
- 按钮标签：`导入为训练点`
- 导入后的成功提示仍保留薄弱点编号，避免用户找不到已导入记录。

底层仍调用 `Storage.import_lesson_as_weak_point()`，所以不会影响旧数据。

### 2. 可执行训练计划

课程生成提示词要求模型输出可执行字段，但继续落入现有字段：

- `objective`：写成“本课目标 + 完成标准”。
- `knowledge_points`：保留短考点名，便于导入为训练点。
- `mistake_risks`：保留具体错因，并优先写成可纠正动作。
- `recommended_template`：仍从现有 6 个苏格拉底模板中选择。
- `review_plan`：升级为可执行安排，包含预计用时、当日任务、追问练习、复盘要求和间隔复习。

页面展示时改成任务卡风格：

- 目标
- 训练点
- 易错风险
- 苏格拉底模板
- 执行安排

### 3. 首次使用指引

在“今日学习”顶部加入轻量指引区，只用 `st.session_state` 控制显示与收起，不写数据库。

指引内容：

1. 录入薄弱点或从课程导入训练点。
2. 进入苏格拉底训练，用追问暴露真实薄弱点。
3. 到周度/月度复盘查看高频考点和错因。

动画使用 CSS transition 和 keyframes，只作为视觉提示，不阻塞操作。

## 数据影响

- 不新增表。
- 不新增字段。
- 不执行迁移。
- 不修改用户已有薄弱点、训练记录、上传资料、课程和 RAG 片段。
- 旧课程仍可正常展示；缺少新格式细节时按普通文本显示。

## 验收标准

- `services.versioning.APP_VERSION` 升级为 `0.5.0`。
- 课程生成 prompt 明确要求“可执行训练计划”，不再只生成大纲。
- `normalize_lessons()` 能兼容模型返回的字符串、数组和缺省字段。
- 资料知识库页面显示“可执行训练计划”相关文案。
- 课程小节导入入口显示“训练点科目”和“导入为训练点”。
- 今日学习页出现可关闭的新手指引。
- 自动化测试通过。
- 编译检查通过。
- 本地 Streamlit 首页 HTTP 检查通过。
