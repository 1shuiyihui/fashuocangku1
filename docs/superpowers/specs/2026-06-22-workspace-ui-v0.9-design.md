# v0.9.0 Workspace UI 重构设计

## 目标

把应用从“Streamlit 表单集合”重构为更接近飞书工作台的学习闭环界面，重点覆盖左侧边栏、训练点录入、苏格拉底训练、资料知识库和可执行训练计划。

## 范围

- 左侧边栏增加品牌区、系统状态、学习闭环和分组导航。
- 录入页改为“上传或拍照 → 结构化训练点 → AI 抽取与确认”的三步工作台。
- 训练页改为“训练上下文条 + 对话区 + 训练控制台 + 复盘保存”的结构。
- 资料页改为“上传并建立索引 → 检索资料片段 → 生成可执行训练计划 → 导入为训练点”的闭环。
- 课程小节展示为训练计划卡片，并继续使用现有“导入为训练点”逻辑。

## 非目标

- 不修改数据库 schema。
- 不改 OCR、PDF 抽取、RAG 检索和课程生成算法。
- 不新增只有前端展示、没有业务动作的按钮。
- 不迁移或清空 `data/` 用户数据。

## 数据影响

本次是 UI 和文档更新。运行应用时仍会按现有逻辑读写：

- `data/fashuo.db`
- `data/uploads/`
- `data/documents/`

没有 schema 变更，不需要数据库迁移。若部署在 Streamlit Cloud，仍需检查页面顶部是否显示 `AI 已配置` 和 `GitHub 云端快照`。

## 验收标准

- v0.9.0 版本号显示正确。
- 左侧边栏能看到系统状态、学习闭环和页面分组。
- 录入页能保存训练点，并能跳转到苏格拉底训练。
- 训练页能选择训练点、模板、预览提示词、开始训练和保存复盘。
- 资料页能上传资料、检索资料片段、生成训练计划，并把小节导入为训练点。
- 所有既有测试通过，页面启动可访问。
