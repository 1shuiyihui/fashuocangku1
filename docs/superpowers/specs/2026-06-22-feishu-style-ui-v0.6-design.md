# v0.6.0 飞书风格 UI 重构设计

## 目标

把现有 Streamlit 应用重构成更接近飞书工作台的办公产品界面：左侧分组导航、顶部状态栏、清晰的工作台首页、统一的浅灰背景和白色内容区。重点是提升第一次使用者的可理解性和日常复盘效率，不改变现有业务流程。

## 范围

本版本只修改 UI 层、页面布局、样式常量、版本号、测试和文档。

不做以下事情：

- 不改数据库表结构。
- 不迁移 `data/fashuo.db`。
- 不改 `data/uploads/` 或 `data/documents/`。
- 不更换 Streamlit 技术栈。
- 不引入 React/FastAPI。
- 不改变 OCR、RAG、课程生成、苏格拉底训练的核心业务逻辑。

## 信息架构

左侧导航按飞书式工作台分组：

- 学习：今日学习、错题/薄弱点录入、苏格拉底训练
- 资料：资料知识库、模板管理
- 分析：薄弱点分析、周度/月度复盘
- 系统：系统与备份

导航使用按钮式分组列表代替单个长 radio，保持页面数量不变。

## 顶部栏

每个页面顶部显示统一工作台头部：

- 当前页面名称
- 所属分组
- 应用版本
- AI 配置状态

页面内部不再重复大标题，避免首屏被标题占满。

## 首页工作台

`今日学习` 作为默认工作台：

- 顶部保留新手三步指引。
- 核心指标使用横向卡片显示：薄弱点、训练次数、完成训练。
- 下一步建议作为主行动区。
- “建议优先处理”作为任务列表展示。

## 视觉规范

- 主背景：浅灰。
- 内容块：白色、1px 边框、8px 圆角。
- 主色：蓝色，接近飞书办公产品风格。
- 字体层级：顶部标题清楚，页面内标题更克制。
- 交互：按钮、输入框、展开区统一圆角和 hover 状态。
- 动画：只保留轻量淡入，不做复杂动画。

## 数据影响

- 数据库结构不变。
- 不执行 migration。
- 不读写用户已有数据。
- 不新增数据文件。
- 不影响已保存薄弱点、训练记录、资料、RAG 片段或课程。

## 验收标准

- `APP_VERSION` 为 `0.6.0`。
- 存在 `NAV_GROUPS`，且覆盖所有 `PAGES`。
- `资料知识库` 属于 `资料` 分组，`周度/月度复盘` 属于 `分析` 分组。
- 全局样式包含顶部栏、侧边栏、工作台卡片和指标卡样式。
- 页面顶部显示版本号和 AI 状态。
- 今日学习页仍能展示三步指引、指标和下一步建议。
- 自动化测试通过。
- 本地 HTTP 检查通过。
- 浏览器烟测确认首页和资料页可以打开，视觉 shell 生效。
