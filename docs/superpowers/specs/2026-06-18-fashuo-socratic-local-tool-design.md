# 法硕苏格拉底本地学习工具设计

## 目标

构建一个面向法硕考研的本地学习工具，把 Socratic 追问式学习迁移到考前薄弱点诊断、错题修复、周度复盘和月度复盘场景。第一版重点不是复刻任何现有产品外观，而是实现一个可立即使用的本地原型：实体书错题通过照片留档，用户少量手动标注，系统围绕薄弱考点启动可配置提示词驱动的苏格拉底训练，并基于训练记录生成复盘。

## 范围

第一版包含：

- 错题/薄弱点录入，支持上传实体书照片。
- 法硕科目、题型、考点、错因、掌握度等字段的结构化记录。
- 可编辑的 App 内提示词模板管理器。
- 围绕薄弱点的苏格拉底式 AI 追问训练。
- 训练记录、消息记录、模板快照和训练总结保存。
- 薄弱点统计、考前优先级排序。
- 周度复盘和月度复盘报告。
- 复盘报告以 Markdown 形式展示，便于复制保存。

第一版不包含：

- OCR 自动识别题干。
- 自动从照片判断考点。
- 用户账号、云同步、计费和 token 系统。
- 复杂教材库、社区和角色世界观系统。
- 立绘、动画或商业产品级视觉包装。

## 核心学习流程

1. 用户录入错题或薄弱点，上传实体书照片，并填写科目、题型、考点、错因和掌握度。
2. 用户从模板库中选择追问模板，也可以在训练开始前临时修改提示词。
3. 系统把固定法硕导师规则、模板正文、薄弱点数据、用户目标和近期薄弱点合成为本次训练提示词。
4. AI 每次只问一个问题，不直接给完整解析。
5. 用户回答后，AI 判断回答质量，再选择继续追问、提示、纠错或提高难度。
6. 用户结束训练后，系统生成掌握度评估、暴露问题、复习建议和下次训练建议。
7. 周度和月度复盘使用错题记录、训练记录和掌握度变化生成分析报告。

核心原则：错题不是终点，而是触发针对薄弱考点的追问训练。

## 页面结构

### 今日学习

展示当天最值得处理的内容：

- 今日待复习考点。
- 最近反复出错的考点。
- 一键开始苏格拉底追问。
- 本周学习状态摘要。

### 错题/薄弱点录入

支持图片上传和少量结构化字段：

- 照片。
- 科目：刑法、民法、法理、宪法、法制史。
- 题型：单选、多选、简答、论述、案例分析。
- 考点。
- 错因：概念混淆、要件遗漏、法条不熟、案例事实误判、记忆不牢、表达不规范。
- 掌握度：陌生、模糊、基本会、熟练。
- 题干、参考答案、备注，均为可选。

### 苏格拉底训练

围绕一个错题或考点启动训练：

- 选择追问模板。
- 训练前临时编辑提示词。
- 选择仅本次使用，或保存为新模板。
- AI 每轮只问一个问题。
- 用户回答后，AI 继续追问、纠错或要求补充采分点。
- 结束后生成训练总结。

### 模板管理

实现轻量 App 内模板管理：

- 查看内置模板。
- 新建模板。
- 复制模板。
- 修改模板。
- 禁用模板。
- 保存模板版本。
- 每次训练保存当时使用的模板快照。

### 薄弱点分析

结合错题和训练表现：

- 按科目统计错误次数。
- 按考点统计反复出错情况。
- 按错因统计高频问题。
- 标记训练后仍掌握度低的考点。
- 生成考前优先复习清单。

### 周度/月度复盘

输出可读报告：

- 本周或本月学习量。
- 新增薄弱点。
- 已改善考点。
- 反复失败考点。
- 高频错因。
- 下周或下月复习计划。
- 推荐优先进行的苏格拉底训练。

## 提示词模板系统

模板由数据库管理，不写死在代码中。每个模板包含：

- 模板名称。
- 适用科目。
- 适用题型。
- 模板正文。
- 默认训练目标。
- 结束条件。
- 是否启用。
- 版本号。

模板正文支持变量：

```text
{subject}
{question_type}
{knowledge_point}
{mistake_reason}
{mastery_level}
{question_text}
{reference_answer}
{student_goal}
{recent_weaknesses}
```

系统在每个模板外固定注入基础规则：

```text
你是法硕考研苏格拉底式导师。
目标是通过连续追问帮助学生掌握考点，而不是直接灌输答案。
每次只问一个问题。
不要一次性给完整解析。
学生回答后，先判断回答质量，再决定追问、提示、纠错或提高难度。
训练内容必须围绕法硕考试表达、考点辨析、案例适用和主观题采分点。
```

每次训练必须保存：

- 模板 ID 和版本号。
- 本次实际提示词快照。
- 对话全文。
- AI 最终评估。
- 训练前后掌握度。

这样后续模板变更不会污染历史训练记录和复盘。

## 内置模板

第一版内置 6 个可编辑模板：

- 概念辨析追问：用于易混概念，例如盗窃罪与侵占罪、无权代理与表见代理。
- 构成要件追问：用于定义、主体、客体、主观、客观、法律效果。
- 案例分析追问：用于识别法律关系、争点、规则适用和结论。
- 主观题采分追问：按定义、要件、展开、适用、结论检查答题完整性。
- 考前速记追问：以高频短问答检查背诵漏洞。
- 错因修复追问：根据标注错因设计补救问题。

## 技术实现

第一版采用本地 Streamlit 应用：

- 界面：Streamlit。
- 数据库：SQLite。
- 图片存储：本地 `data/uploads/`。
- AI 调用：OpenAI-compatible API。
- 配置：通过 `.env` 或侧边栏输入 API base、model 和 API key。
- 运行：本地浏览器访问 `http://localhost:8501/`。

建议项目结构：

```text
fashuo-socratic/
  app.py
  data/
    fashuo.db
    uploads/
  services/
    ai_client.py
    analysis.py
    prompts.py
    storage.py
  prompts/
    seed_templates.py
  requirements.txt
  README.md
```

## 错误处理

- AI API 未配置时，训练页面显示配置提示，并允许继续管理错题和模板。
- AI 调用失败时，保留用户当前输入和会话记录，提示重试。
- 图片上传失败时，不阻塞手动录入文本薄弱点。
- 模板变量缺失时使用空字符串填充，并在预览中显示最终提示词。
- 数据库初始化失败时，应用停止并显示明确错误。

## 测试与验证

第一版验证重点：

- 数据库能初始化并写入内置模板。
- 能新增、编辑、复制、禁用模板，并生成版本记录。
- 能新增错题/薄弱点并上传图片。
- 能选择薄弱点和模板生成提示词快照。
- 能保存训练消息和训练总结。
- 薄弱点分析能按科目、考点、错因聚合。
- 周度/月度复盘能基于真实记录生成报告。
- 未配置 AI API 时，非 AI 功能仍可使用。
